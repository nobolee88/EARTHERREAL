## Quick Start

### Installation

```bash
# Requires SBCL and Quicklisp
git clone https://github.com/[YOUR-USERNAME]/lisp-infinity.git
cd lisp-infinity
sbcl --load src/lisp-infinity.asd
```

### Basic Usage

```lisp
(ql:quickload :lisp-infinity)

;; Create entangled quantum states
(let ((q0 (create-quantum-state 2))
      (q1 (create-quantum-state 2)))
```
